# Сайт AILang: використання та розміщення

Ідея: надати презентацію мови, її документацію та стартовий архів для нового проєкту у вигляді звичайного статичного сайту.

Версія файла: 0.9.0. Дата: 2026-11-15.

## Готові файли

- [Головна сторінка](../.Результат/Сайт/index.html) — українська.
- [English](../.Результат/Сайт/en/index.html) — англійський інтерфейс.
- [Документація](../.Результат/Сайт/docs/index.html) — усі 21 авторський файл, навігація, пошук за назвою та вмістом, зміст розділу, копіювання тексту й завантаження Markdown.
- [Стартовий ZIP](../.Результат/Сайт/downloads/ailang-0.9.0-uk-starter.zip) — правила та структура нового проєкту.
- [Архів для сервера](../.Результат/Публікація/ailang-site-0.9.0.zip) — увесь готовий сайт.

Сайт написаний на HTML, CSS і JavaScript. Працює без серверного коду, бази даних, CDN, завантаження зовнішніх шрифтів і встановлення залежностей. Навігація й завантаження доступні без JavaScript; JavaScript додає пошук, мобільне меню та копіювання.

## Як завантажити на сервер

1. Розпакуйте архів `ailang-site-0.9.0.zip` на своєму пристрої.
2. Завантажте **вміст** архіву в кореневу папку сайту або окрему підпапку на сервері. `index.html`, `assets`, `docs`, `en`, `source` та `downloads` мають бути поруч.
3. Налаштуйте сервер на віддавання статичних файлів та `index.html` як індексного документа. HTML і текстові файли мають віддаватися в UTF-8, `.js` — як JavaScript, `.css` — як CSS, `.zip` — як ZIP або двійковий файл.
4. Відкрийте адресу сайту. Перейдіть до документації, перемкніть мову та завантажте стартовий архів.

Посилання відносні, тому сайт підтримує розміщення в підпапці, наприклад `/ailang/`. SPA-перенаправлення всіх URL на index.html не потрібне: документація складається зі звичайних HTML-сторінок. `.nojekyll` доданий для сумісності з GitHub Pages. На сервер переноситься лише готовий сайт, а не весь репозиторій.

Генератор не знає майбутнього домену. Для повноцінних Open Graph-прев’ю після вибору адреси можна додати абсолютні `og:image`, `og:url` та canonical URL. Основне зображення вже постачається як `assets/banner.png`.

## Що містить стартовий архів

- `.AILang/.Джерело` — усі авторські правила та шаблони налаштувань, включно з прихованими папками.
- `.AILang/VERSION` — версія пакета AILang.
- Кореневий `AGENTS.md` — шаблон входу для агента; власник може доповнити його.
- `ПОЧАТОК.md` — інструкція налаштування; авторство шаблону не визначає авторство нового продукту.
- Кореневий `VERSION` — початкова версія **нового продукту** 0.1.0.
- Папки `.Ідея`, `.Джерело`, `.Результат`, `.Документація`, `.План`, `.Постачальники`, `.Інструменти`, `.Залежності`.

Розпаковуйте стартовий архів у порожню папку. Під час додавання AILang до існуючого проєкту узгодьте міграцію та збережіть власний AGENTS.md. ZIP створюється зі списку авторських файлів; дані сеансу, Git і секрети до нього не додаються. Побайтову відповідність перевіряє SHA-256 під час збирання. Контрольна сума готового ZIP постачається поруч у `.sha256`.

## Оновлення сайту

Після авторських змін у `.Джерело` або зміни `VERSION` виконайте в корені репозиторію:

```powershell
python -B .Сайт/Зібрати.py
```

Потрібен Python 3.11 або новіший зі стандартною бібліотекою. Скрипт читає `.Джерело`, `VERSION` і обрані медіафайли; формує сайт, стартовий архів і архів для сервера у `.Результат`. Він не змінює авторські правила, не встановлює ПЗ й не розгортає сайт. Для нового файла джерела доповніть перелік `DOCUMENTS` у `.Сайт/Зміст.py`; інакше збирання зупиниться, щоб документація не пропустила файл. Якщо файл видалений або перейменований, перед збиранням приберіть відповідні застарілі згенеровані сторінки; артефакти інших версій видаляються окремо за рішенням власника.

Інтерфейс uk/en зберігається в `.Сайт/Зміст.py`, оформлення — в `site.css`, взаємодії — в `site.js`. Авторські правила на сторінках залишаються українськими; англійська версія явно повідомляє про це.
