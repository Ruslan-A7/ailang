# AILang — огляд проєкту

Ідея: створити обгортку інструкцій для правильного сприйняття та максимально точної реалізації авторського опису ПЗ.

Версія: 0.6.3. Дата: 2026-10-19. Статус: робоча українська редакція, не завершений випуск.

## Призначення

ПЗ описує автор у .Джерело (англійська роль — .Source). AILang надає інструкції, пояснення й правила сприйняття та реалізації цього опису. Суть результату має максимально відповідати ідеї та вимогам автора. Побітова тотожність результатів різних моделей чи ітерацій не вимагається.

Авторські джерела: [AGENTS.md](../AGENTS.md), [ідея](../.Ідея/AILang.md), [уточнення](../.План/Уточнення.md). Оригінали не переписані.

## Структура

| Шлях | Призначення |
| --- | --- |
| .Ідея | Авторські матеріали лише для читання |
| .Джерело | Початковий опис, після ініціалізації змінює автор |
| .Документація | Агентська документація |
| .План | План, вимоги, рішення й продовження |
| .Результат/uk | Український результат розробки AILang |
| .Інструменти | Допоміжне ПЗ цього репозиторію |
| .Залежності | Дзеркало тільки фактичних зв'язків файлів джерела |
| .Налаштування | Параметри цього репозиторію за винятком початкової розробки |

У цьому репозиторії немає кореневої .AILang: ми розробляємо саму мову. AGENTS.md зберігає ім'я та авторський вміст. .Doc і .Plan перейменовані українською; Problems → Проблеми.

Головний файл результату: [Інструкції/Agents.md](../.Результат/uk/Інструкції/Agents.md). У цільовий проєкт копіюється вміст .Результат/uk до .AILang без підпапки uk. Інші локалізації en/de/fr/es будуть поряд з uk після завершення першої української версії.

Мови спілкування, джерела, коментарів, документації, продукту, авторство та ліцензію задає кожний проєкт у власних налаштуваннях. Значення RA7 та українська мова цього репозиторію не переносяться на чужі продукти.

## Ітерація v0.3.0

Додано українську структуру, погоджені уточнення, модульне ядро, конфігурації, правила перегляду їх змін, відповідності й ініціалізації. Створено Windows-планувальник та CLI-адаптери з окремою документацією. Авторські приклади іншого проєкту збережені без змін.

Залишаються остаточна перевірка повноти ядра, повні приклади, комплект постачання інструментів, матеріали v1.0.0 та переклади. Наявність ядра не означає завершення всієї мови.

У v0.4.0 розширено ручний таймер, створення/збереження й вибір історії; автоматичний цикл становить 05:05. Додано режими схвалень за присутністю автора, локальний журнал та Git-параметр спільного коміту ручних змін автора й агента. Відкладене надсилання в цій ітерації не активується саме по собі.

У v0.4.1 виправлено запуск .cmd через ASCII/CRLF та окремий PowerShell-вхід з обробкою помилок. Автор підтвердив відкриття вікна v0.4.1 саме через запускатор; автоматичну роботу під час діагностики не вмикали.
