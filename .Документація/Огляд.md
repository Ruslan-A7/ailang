# AILang — поточний стан

Ідея: використовувати авторський набір правил без додаткового переписування мовою агента.

Версія файла: 0.11.1. Дата: 2026-11-20.

Сама AILang міститься в авторській папці [.Джерело](../.Джерело/AGENTS.md). Її файли є придатними для читання агентом інструкціями. Окремий згенерований пакет правил не потрібен. Папка .Ідея містить авторський контекст.

Для встановлення скопіюйте папку .Джерело цілком, включно з прихованими .Інструкції та .Налаштування, до .Постачальники/RA7/AILang у цільовому проєкті. Вхідний файл: .Постачальники/RA7/AILang/.Джерело/AGENTS.md. Налаштування заповнює власник цільового проєкту.

Правила автономної роботи містяться в .Джерело/.Інструкції/Ліміти та автоматизація.md. Агент використовує доступні засоби очікування та достовірне читання квот свого середовища. Доступність цих можливостей залежить від середовища; сам таймер не підтверджує відновлення квот.

У .Результат/Медіа зберігаються обрані логотип і заставка. .Результат також призначена для локалізованих версій самої AILang: en/de/fr/es. Авторський український набір залишається в .Джерело.

Статичний сайт у .Результат/Сайт має інтерфейси uk/en, повну документацію з авторських файлів, пошук і стартовий ZIP для нового проєкту. Оригінали в архіві збережені побайтово. Англійська навігація не означає, що правила вже перекладені.

Вихідні файли сайту — .Сайт; збирання та перенесення описані в [Сайт.md](Сайт.md). Архів сайту розміщений у .Результат/Публікація. README українською та англійською пояснюють початок використання. Поточна версія проєкту визначається VERSION; позначки версій файлів оновлюються лише зі зміною їхнього змісту.
