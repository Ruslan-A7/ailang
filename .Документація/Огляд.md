# AILang — поточний стан

Ідея: використовувати авторський набір правил без додаткового переписування мовою агента.

Версія файла: 0.8.0. Дата: 2026-11-15.

Сама AILang міститься в авторській папці [.Джерело](../.Джерело/AGENTS.md). Її файли є придатними для читання агентом інструкціями. Окремий згенерований пакет правил не потрібен. Папка .Ідея містить авторський контекст.

Для встановлення скопіюйте папку .Джерело цілком, включно з прихованими .Інструкції та .Налаштування, до .AILang у цільовому проєкті. Вхідний файл: .AILang/.Джерело/AGENTS.md. Налаштування заповнює власник цільового проєкту.

Правила автономної роботи містяться в .Джерело/.Інструкції/Ліміти та автоматизація.ail.md. Агент використовує доступні засоби очікування та достовірне читання квот свого середовища. Доступність цих можливостей залежить від середовища; сам таймер не підтверджує відновлення квот.

У .Результат/Медіа зберігаються обрані логотип і заставка. README українською та англійською пояснюють початок використання. Поточна версія проєкту визначається VERSION; позначки версій файлів оновлюються лише зі зміною їхнього змісту.
