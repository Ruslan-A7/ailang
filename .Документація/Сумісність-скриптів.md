# Пам'ятка сумісності допоміжних скриптів

Ідея: зберегти практичний висновок виправлення запускатора для наступних ітерацій цього проєкту.

Версія: 0.6.5. Дата: 2026-10-19. Нормативні правила: [Інструменти.md](../.Результат/uk/Інструкції/Інструменти.md).

У v0.4.0 запускатор блимав консоллю без GUI; прямий запуск PowerShell відкривав вікно. У v0.4.1 допомогли ASCII/CRLF для .cmd, окремий Launch.ps1, UTF-8 BOM для українського PowerShell та обробка ранніх помилок. Автор підтвердив запуск саме через .cmd. Це спостереження про конкретну комбінацію запуску й кодування, не доказ, що українська мова або Unicode загалом несумісні зі скриптами.

До наступної роботи зі скриптами перечитати цю пам'ятку та правила мови. Зберігати українські назви папок і текст UI; ASCII допускається для мінімального технічного входу. Для ресурсів — PSScriptRoot/еквівалент, явне кодування, коректні аргументи та переноси рядків за рушієм. Фактичний .cmd необхідно відрізняти від окремо запущеного .ps1.

[Документація Microsoft](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_character_encoding?view=powershell-5.1) пояснює, що Windows PowerShell може сприймати UTF-8 без BOM як ANSI; для не-ASCII тексту в його скриптах потрібен UTF-8 BOM. Це правило не застосовується без змін до Unix-інструментів та PowerShell 7.
