# Підтримка .ail у редакторі

Ідея: сприймати вихідний опис як Markdown без зміни розширення та глобальних налаштувань.

Версія: 0.6.4. Інструкція створення локальної асоціації замінює окремий універсальний інсталятор, оскільки IDE мають різні механізми.

У VSCode власник додає або об'єднує з наявним files.associations у налаштуваннях саме робочого простору, за [офіційною документацією VSCode](https://code.visualstudio.com/docs/languages/overview#_add-a-file-extension-to-a-language):

```json
{
  "files.associations": {
    "*.ail": "markdown",
    "*.ail.md": "markdown"
  }
}
```

Не перезаписуйте весь наявний settings.json; збережіть інші ключі та асоціації. Альтернатива без запису файлів — обрати Markdown через перемикач режиму мови редактора для відкритого .ail. Для інших IDE використовуйте локальну асоціацію розширення з Markdown; якщо її немає, .ail.md підтримується як звичайний Markdown.

Ця інструкція не запускає жодного коду й не змінює глобальну конфігурацію. Правила синтаксису AILang залишаються однаковими для обох розширень.
