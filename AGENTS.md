# AILang

Я хочу створити спеціалізовану мову програмування з використанням ШІ-агентів, яка має називатись AILang.
Це набір інструкцій, специфікацій та правил опису будь-якого програмного забезпечення будь-якою людською мовою для максимально точного та коректного відтворення бажаного функціоналу будь-яким ШІ-агентом на будь-якій мові програмування.

Ознайомся з .Ідея\AILang.md та допоможи завершити розробку, структурувати й розділити та достатньо її описати на основі вмісту та вимог AILang.md:
- **не прибирай** нічого і нічого не пропусти (якщо вважаєш, що щось краще прибрати - повідом)
- можеш запропонувати доповнення/покращення/рішення і виправлення уже написаного для реалізації чи при конфліктах вимог
- підказати можливо якщо я упустив якийсь важливий момент

При створенні цієї мови одразу **дотримуйся** інструкцій записаних в AILang.md.

Можеш враховувати та брати за приклад інструкції із загальних налаштувань Codex в цьому акаунті (загальний AGENTS.md). Особливо про версіювання та безпеку, приватність, секрети проекту. Правила локалізації **мають** враховувати мови визначені в налаштуваннях мови для проекту.

Готовим результатом цього проекту **слід** вважати готовий, структурований набір інструкцій, специфікацій та правил опису ПЗ, які допоможуть ШІ-агентам максимально точно реалізувати ідею автора оптимізуючи та полегшуючи процес розробки.

Додатково для публікації v1.0.0 **треба** створити:
- футуристичний логотип та заставку AILang
- красивий сучасний html, js, css сайт-презентацію цієї мови для розміщення на github pages
- readme файл проекту для github з описом та ідеєю мови, а також інструкція для початку використання
- напиши текст пісні та промт для опису стилю для генерації пісні про цю мову та ШІ програмування зробивши слово AILang центральним та періодично повторюваним (але щоб це було доречно) за допомогою suno.ai

Початковий коміт v0.1.0 та публікацію на github я зроблю самостійно, а далі в межах цього проекту коміть та пуш самостійно.
