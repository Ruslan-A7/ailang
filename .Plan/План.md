# План розробки AILang

Ідея: вести реалізацію від незмінної авторської ідеї до перевіреного комплекту мови без втрати вимог.

Версія: 0.2.0. Дата: 2026-10-18.

## Виконано у v0.2.0

- Прочитано всі наявні робочі файли проєкту: AGENTS.md, .Ідея/AILang.md, .gitignore; перевірено стан Git і наявність початкового коміту v0.1.0.
- Збережено авторські матеріали без змін.
- Створено огляд, карту тематичних вимог і реєстр суперечностей із варіантами рішень.
- Автор відповів «Потрібно обговорити окремо» на спільне запитання про пріоритети, авторські файли та H1. Жодне із трьох уточнень не погоджено.

## Наступні етапи

| Етап | Результат | Статус |
| --- | --- | --- |
| Уточнення | Окремі рішення P01–P03, права створення системних файлів P04, параметри P05–P06 | Очікує обговорення |
| Ядро | Тематичні Markdown-інструкції та точна відповідність кожному пункту джерела | Не розпочато |
| Конфігурація | Окремі Dev/Result, дозволи, ліміти, міграція, локалізації | Не розпочато |
| Практичне використання | Шаблони, швидкий старт, декілька простих прикладів, граф залежностей | Не розпочато |
| Інструменти | Підтримка .ail та автоматизація або інструкції адаптації для середовища | Не розпочато |
| Переклади | Повні en/de/fr/es зі збереженням структури та змісту | Не розпочато |
| Матеріали випуску | README, логотип, заставка, HTML/CSS/JS сайт для GitHub Pages, текст пісні та Suno-промт | Не розпочато |
| Приймання | Перегляд повноти вимог, посилань, атрибуції та перекладів; підготовка використання | Не розпочато |
| Подальший розвиток | Фреймворк на AILang | Відкладено згідно задуму |

Версії наступних ітерацій визначаються за фактичним обсягом змін. Перехід на 1.0.0 — лише за прямою вказівкою автора після завершення критеріїв випуску. Наявність матеріалів сайту не означає дозволу на його розгортання.

## Місце продовження

Обговорити P01, потім P02 та P03 з [реєстру](Problems/Рішення.md) окремими запитаннями. Не змінювати авторські інструкції для усунення конфліктів. Після погодження записати рішення з датою і перенести погоджені формулювання у специфікацію.

Перевірка цієї ітерації: читання створених Markdown-файлів та безпечного diff. Виконуваного продукту ще немає. Лічильник лімітів у поточному інтерфейсі недоступний; автоматизація не встановлена й не активована.
