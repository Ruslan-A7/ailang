Локалізація проекту

  • мова проекту: українська (пріоритетна), англійська, можливо пізніше ще французька, німецька, іспанська
  • мова документації: українська (пріоритетна), англійська

Стек технологій для реалізації

  • бажаний стек технологій для результату: Tauri 2, P2P, Rust, PHP, HTML, JS, CSS
  • підтримувані платформи: Windows 10/11+, Android 10+, Linux

Правила версіювання

  • починай з 0.1.0 згідно semver.org
  • версію 1.0.0 можна буде призначити лише після моєї вказівки
  • джерело поточної версії: VERSION; UI читає поточну версію з єдиного джерела

Дозволи

  • дозвіл на редагування в .Джерело: заборонено
  • дозвіл на використання іншого ПЗ: дозволено встановлення та використання ПЗ з наступного списку:
    • Git
    • Docker
    • Samba
    • інше ПЗ на мою вимогу або після мого погодження
  • Git:
    • використовуй Git та локальні коміти називаючи кожен коміт за принципом "vX.Y.Z: опис"
    • спільний коміт змін автора й агента: увімкнено
    • поки я не дозволю самостійно не роби push
  • GitHub: не публікуй нічого на GitHub поки я не зроблю самостійно першу публікацію в приватний або публічний репозиторій та не дам дозвіл на самостійну публікацію - лише після дозволу можна буде роби push у відповідний репозиторій

  • стандартний поріг тижневого ліміту: 5%
