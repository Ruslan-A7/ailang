01 / THE IDEA

Meaning first.
Syntax follows.

Software starts with what you want to create. AILang helps preserve that meaning throughout development, from the first description to the final result.

It is a set of instructions, specifications, and rules for an agent. The author describes the product in natural language; the agent implements it using the agreed stack. Models may produce different code. Your requirements and intent remain the reference.

.Source / Task list.ail
ILLUSTRATIVE AUTHOR DESCRIPTION
# Personal task list

Idea: help me plan my day.

- **I can add a task with a title.**
- **Completed tasks are preserved.**
- I can hide completed tasks.

Acceptance: the new task is listed.

An example description, not a finished app. Bold text marks mandatory requirements.

02 / FEATURES

Room for ideas.
Clarity for development.

Markdown · .ail · .ail.md
01

Write in human language

Capture intent, behavior, requirements, and context in Markdown. Start with the essentials and refine the details.

02

Choose your stack

The rules are independent of a specific programming language or paradigm. Your project defines the stack and platforms.

03

Stay in control

Author-owned materials, permissions, and settings have defined roles. The agent reads the requirements before implementation.

04

Keep track of dependencies

Relationships between files help the agent assess the impact of changes and keep the project consistent.

05

Keep context accessible

Ideas, source descriptions, output, documentation, and plans have separate places so the agent can find what matters.

06

Continue with context

Quota, waiting, and continuation rules help organize autonomous work using the capabilities of the agent’s environment.

03 / GET STARTED

From a download to your first idea.

Download and extract

Extract the starter ZIP into an empty project directory. The rules are already in .Постачальники/RA7/AILang/.Джерело.

Configure your project

Set attribution, languages, stack, and permissions in .Постачальники/RA7/AILang/.Джерело/.Налаштування/Налаштування.md.

Describe your product

Add context to .Ідея and describe the desired behavior in your root .Джерело using .ail or .ail.md files.

Give the agent your intent

Ask it to read AGENTS.md, the rules, and your description. The agent should read, clarify important details, and plan.
