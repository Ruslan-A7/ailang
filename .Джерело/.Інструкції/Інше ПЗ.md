# Взаємодія з іншим програмним забезпеченням (ПЗ)

- Дозволено встановлювати, використовувати встановлені та створені під час роботи програми, рушії, сервери й контейнери **лише для реалізації поточного проєкту**. Це **НЕ дозволяє** досліджувати сторонні дані чи змінювати глобальні налаштування.

- Якщо потрібне ПЗ вже встановлено - не потрібно встановлювати його повторно без потреби (окрім випадків коли треба інша версія або автор вимагає) - за можливості **використовуй наявне ПЗ**.
