## Дослідження автоматизації

Оригінальний deferred-monitor.ps1 лише читає first.json/cycle.json і не надсилає запити. Повний комплект тепер міститься безпосередньо у .Ідея/Приклади/Автоматизація роботи: deferred-resume.ps1 використовує codex queue; deferred-launch.ps1 запускає його через Task Scheduler, first/cycle обгортки задають режим. На пряме доручення автора «Не повні» видалено, вміст «Повні робочі інструменти» перенесено вище, порожню папку прибрано. Вміст повного комплекту та reference не редагувався.

Прочитано довідку встановленого Codex 0.162.0-alpha.17.2 та офіційну документацію. /status — інтерактивна команда, не shell-команда і не модельний запит codex exec. Машинне читання використовує account/rateLimits/read; невідомі дані не підміняються відсотками.

Читання квот через новий адаптер спрацювало 2026-10-19 о 02:14 за Києвом: 79% залишку п'ятигодинного та 97% тижневого вікна. Звичайний запуск скрипта заблокувала execution policy; схвалений запуск RemoteSigned тільки для дочірнього процесу спрацював без глобальних змін. GUI та надсилання не запускалися.

Планувальник доставляє в явно вказаний UUID через queue, наявність якої підтверджена локальною довідкою. Прийняття доставки не означає завершення роботи агента; повтор рахується від доставки. Після помилки повтор вимкнений. У новому прикладі один таймер з історією та перевіркою квот, без реєстрації завдань Windows; в оригіналі два фонові відліки через Task Scheduler. Оригінали не запускаються. Вимкнення ПК не активоване. GUI та доставка у реальний чат не перевірялися.

## Залишилося

Остаточна деталізація й перегляд кожного нормативного пункту, приклади, перевірка GUI/інтеграції під час використання, комплект інструментів для постачання, матеріали випуску та переклади. Це не статус готовності v1.0.0.
