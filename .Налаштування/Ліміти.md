# Ліміти поточного проєкту

Ідея: достовірний стан і контрольоване продовження.

Версія: 0.5.0. Схема: 0.1.0. Надалі змінює автор.

- Перевіряти доступні ліміти підтриманим каналом під час тривалої роботи.
- /status у Codex CLI — інтерактивна команда, не команда shell чи модельний запит.
- Машинний адаптер: .Інструменти/Автоматизація/Адаптери/Ліміти-Codex.ps1.
- Поріг зупинки: залишок 5-годинного вікна ≤10%, тижневого ≤5%.
- Відсутні/непідтримані дані: стан невідомий, без вигаданих відсотків.
- Перед зупинкою зберегти виконане, невиконане, проблеми, наступний крок і дозволений коміт.
- Перед автоматичним продовженням перечитати фактичні квоти; таймер не підтверджує їх відновлення.
- Після помилки надсилання не повторювати автоматично.
- Інтервал автоматичного повтору: 05:05 (305 хвилин), від прийняття доставки queue. Очікування відомого часу відновлення: додатково 5 хвилин, потім повторне читання квот.
